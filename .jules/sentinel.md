## 2024-08-30 - Path Traversal Vulnerability in Local Image URL Translation
**Vulnerability:** A path traversal vulnerability existed in the `fromLocalImageUrl` function in `electron/main.js`. It accepted `local://` URLs and removed the scheme prefix, returning a string that was later checked using `.startsWith(imagesDir)` to verify it was safely inside the `imagesDir`. However, string prefix checks are vulnerable to path traversal if the path contains `../` or if the user constructs a path that merely shares the same string prefix but refers to a different directory (e.g., `/app/images_backup` starting with `/app/images`). This could allow reading or deleting files outside the expected folder during export or deletion flows.
**Learning:** Checking that a path is contained within a specific directory cannot rely on simple string operations like `startsWith()`. Paths are complex and involve relative segments (`../`) and folder boundaries.
**Prevention:** Always use `path.resolve()` (or `path.normalize()`) to fully resolve and flatten paths before verifying containment. Ensure the check uses an exact boundary match, for instance by checking that the resolved path either equals the intended directory or starts strictly with `resolvedDirectoryPath + path.sep`.
