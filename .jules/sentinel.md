## 2024-09-01 - [Path Traversal in Path Validation]
**Vulnerability:** Simple `.startsWith()` string matching was used for verifying if a given path resides inside a target directory (e.g. `imagePath.startsWith(imagesDir)`), and the `local://` custom protocol handler allowed serving any local file on the system (Arbitrary File Read) without restricting paths to a specific directory.
**Learning:** String-based prefix checks are vulnerable to path traversal or spoofed folder names (e.g., `/user/data/images-fake/secret.txt` starts with `/user/data/images`). Furthermore, custom protocol handlers mapping URLs directly to local file paths without validation act as an LFI (Local File Inclusion) vulnerability.
**Prevention:** Always use `path.resolve()` on both the target path and the base directory. Check that the fully resolved target path starts with the fully resolved base directory PLUS a trailing separator (`path.sep`). For protocol handlers, restrict read access exclusively to expected directories (e.g., `imagesDir`).
