## Sentinel Security Journal
## 2025-02-27 - Path Traversal in Image Deletion and Saving
**Vulnerability:** The application was susceptible to path traversal attacks during note save and deletion. Untrusted `imagePath` properties were validated using a simple `.startsWith(imagesDir)` string check. An attacker could potentially pass a path like `/userData/images/../../etc/passwd`, which might pass the simple prefix check but resolve to an arbitrary file on the system, potentially allowing unauthorized file deletion or saving external files.
**Learning:** Simple string prefix checks (`.startsWith()`) are insufficient for validating file paths against path traversal vulnerabilities in Node.js because they do not account for relative path segments like `..` or symbolic links.
**Prevention:** When validating that a user-provided file path belongs to a specific directory, always use `path.resolve()` to get the absolute path first. Then, ensure the resolved directory path ends with a path separator (`path.sep`) before checking if the resolved input path starts with it. For example: `const resolvedPath = path.resolve(inputPath); const safeDir = path.resolve(baseDir) + path.sep; if (resolvedPath.startsWith(safeDir)) { ... }`
